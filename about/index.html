SonicAudio
记录工具链、编译与踩坑现场

这里放的是平时踩坑、折腾工具链和读书做题的记录。写下来主要是为了自己以后能查,顺便如果对别人有用就更好了。

内容大致集中在这几个方向:

  • 工具链与编译 —— conda 环境管理、gcc 多版本切换、FFTW 这类库的编译过程
  • Linux 与系统 —— 虚拟机时区、时间同步、日常排查
  • AI 编程 —— 编码 Agent 的使用经验与提示策略
  • 数学与杂记 —— 偶尔写点推导和观察

写作原则:尽量给可复现的命令和结论,少铺垫,不堆砌形容词。文中命令如果和你的环境不一致,以你机器的实际输出为准。

站点基于 Hexo + Fluid 构建,托管在 GitHub Pages。
